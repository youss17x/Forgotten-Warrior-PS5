Windows build: Python 3, LLVM/MinGW 23, PS5 Payload SDK 0.45, pacbrew 0.37 homebrew sysroot. Linux works the same way with LLVM_BIN=/usr/bin (clang-18 and ld.lld-18 are picked up).
Set LLVM_BIN, PS5_PAYLOAD_SDK, PS5_HBROOT. Set FW_TOOLS to a directory containing zlib-1.3.1 source.
Run python build-title.py. Output: FWRG00001/. Add --zip to also create FWRG00001-v<version>.zip for a release.
The title ID and contentVersion come from sce_sys/param.json; raise contentVersion before every release.
Host native conversion tools and runtime source/manifests: vendor/ps5-native-tool/.
The 4K video driver vendor/sdl-ps5video/SDL_ps5video.c needs the headers of ps5-payload-dev/SDL at commit 160954cf. The build downloads that source into build-cache/ on first run, or set PS5_SDL_SRC to an extracted copy.
Override compiler paths with FW_CLANG, FW_LLD, FW_HOST_CC and FW_HOST_CXX if needed.
Clean-room runtime regeneration instructions are in the linked boilerplate project; runtime/libc.prx matches its generated companion.
The repository and release contain no original game assets; they remain the property of their owners. For a host self-test, pass --assets <folder with your own extracted game files>.
